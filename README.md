# Reparto en marcha

Браузерная игра для изучения испанского A1.2 (7–11 лет). Прослушайте адрес, проведите курьера через улицы и отдельным нажатием ↑ передайте заказ у выбранного входа.

**[Играть в браузере](https://unicornioespanol.github.io/reparto-en-marcha/)** · [Код на GitHub](https://github.com/unicornioespanol/reparto-en-marcha)

## Как запустить

В Windows дважды нажмите **START_GAME.cmd**. Он запустит локальный сервер и откроет игру в браузере. Пока играете, оставляйте окно сервера открытым; для остановки нажмите Ctrl+C. Нужен Node.js; собранная игра уже находится в `dist/`.

Или выполните в этой папке:

```powershell
npm.cmd run dev
```

Откройте http://127.0.0.1:4173. HTML из `dist/` нужно открывать через HTTP-сервер, поскольку игра использует ES-модули.

## Сборка и проверки

```powershell
npm.cmd ci --cache .tools/npm-cache
npm.cmd run build
npm.cmd test
npm.cmd run test:browser
```

На macOS/Linux используйте `npm` вместо `npm.cmd`. Для браузерных тестов по умолчанию используется установленный Chrome по Windows-пути из `playwright.config.mjs`. Для другого расположения задайте `CHROME_PATH`:

```powershell
$env:CHROME_PATH = 'C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe'
npm.cmd run test:browser
```

`npm.cmd run build` компилирует TypeScript со строгой проверкой типов, проверяет каталог и наличие всех ассетов, копирует статические файлы в `dist/`. На статический хостинг нужно загрузить содержимое `dist/`; относительные пути поддерживают размещение в подкаталоге. Серверная часть, аккаунты и API-ключи не требуются.

## GitHub Pages

В `.github/workflows/pages.yml` подготовлена автоматическая публикация из ветки `main`. GitHub Actions устанавливает зависимости, собирает игру и проверяет логику и браузерные сценарии. Публикация содержимого `dist/` запускается только при переменной репозитория `PAGES_ENABLED=true`. Рабочие файлы, графика и оригиналы аудио хранятся в репозитории; `node_modules/`, `.tools/`, результаты проверок и `dist/` в Git не включаются.

Публичное размещение включается отдельно. В репозитории должен быть выбран источник Settings → Pages → Build and deployment → GitHub Actions, затем в Settings → Secrets and variables → Actions → Variables нужно установить `PAGES_ENABLED=true`. После успешного workflow адрес игры появится в окружении `github-pages`. При включённой публикации следующие push в `main` обновляют сайт автоматически.

В Linux для локальных браузерных проверок сначала выполните `npx playwright install --with-deps chromium`. GitHub Actions делает это автоматически.

## Что есть в игре

- Четыре района, двенадцать адресов и отдельные MP3-файлы es-ES.
- Clásico с тремя попытками и Práctica без ограничения; медленный трафик, звук и Audio y texto.
- Стрелки / WASD, экранные кнопки с удержанием; пробел повторяет адрес, Esc открывает паузу.
- Пауза при потере фокуса, скрытии вкладки и повороте устройства. Столкновения возвращают на последний безопасный тротуар.
- Первый выбранный вход завершает заказ. Удержание ↑ не сдаёт его автоматически.
- Итоги заказов, района и кампании; настройки и завершённые районы сохраняются только в браузере.
- Короткое обучение из стартового экрана и паузы. Пропуск: Pausa → Saltar.
- При ошибке аудио или выключенном звуке показывается полный адрес.
- Саундтрек непрерывно играет по кругу после первого взаимодействия со страницей, в том числе в меню, на паузе и при переключении вкладки. Во время любой реплики, включая повтор в окне результата, музыка становится в 5 раз тише и затем возвращается к обычной громкости. Кнопка **Música** рядом с **Pausa** включает и выключает музыку; выбор сохраняется. На телефоне эта кнопка обозначена нотой ♪. Голос включается отдельно в Ajustes → Voz del pedido.

## Замена озвучки и музыки

Подключены файлы, предоставленные 16 ноября. Оригиналы хранятся в `src/audio/orders/{id}.mp3`, саундтрек — в `src/audio/Reparto en marcha (Gameplay Loop).mp3`. Чтобы обновить звук, замените эти файлы и выполните `npm.cmd run build`. Сборка сама обновляет `public/audio/` и `dist/audio/`; готовый саундтрек находится по относительному пути `audio/music/gameplay-loop.mp3`.

Графика обновлена 15 ноября: используются 12 фасадов WebP, 8 вариантов машин и фургонов и тайлы улиц из предоставленного комплекта. Курьер, пешеходы, получатели, велосипедисты и самокатчики сохранены. Размеры и точки привязки ассетов описаны в `public/art/README.txt` и `src/content/art.ts`.

## Структура

| Путь | Назначение |
| --- | --- |
| `src/content/` | Каталог мест, районы, трафик, проверка данных |
| `src/sim/` | Фиксированный тик, шаги, столкновения, чекпоинты, исход заказа |
| `src/render/` | Canvas 2D, графика из макета, отрисовка снимка симуляции |
| `src/ui/` | Испанский интерфейс, ввод, обучение, кампания и диалоги |
| `src/audio/` | Оригиналы записей и саундтрека, воспроизведение, предзагрузка, отмена, текстовый резерв |
| `src/storage/` | Версионированные настройки и прогресс |
| `public/` | HTML/CSS, фасады и аудио |
| `tests/` | Проверки логики, проходимости и браузерных сценариев |
| `scripts/` | Сборка, локальный сервер и генерация исходных ассетов |

Исходные ТЗ, HTML-макет и PNG-референс сохранены без изменений. Подробности приёмки и ограничения — в [BUILD_REPORT.md](BUILD_REPORT.md).
